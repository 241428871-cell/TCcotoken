# TCcotoken

一个用于 Codex 的 Skill：对齐本机 token 日志和账号额度变化，估算本机与非本机使用额度的比例，并报告估算依据与不确定性。

显示名称：**TCcotoken**。调用名：**`$tccotoken`**。

## 功能

- 读取本机会话中的 token 增量，处理累计计数、缓存、重复记录和 fork 继承。
- 对齐同一账号、同一额度桶、同一统计窗口的官方额度快照。
- 根据当前官方模型费率构造权重代理，并用历史时段标定。
- 分别表示“占已消耗额度比例”和“占周期总额度的百分点”。
- 将自动审查、未知模型和归属不明记录单列，报告敏感性范围。

## 安装

下载本仓库，将 `tccotoken` 文件夹复制到 Codex 的 skills 目录：

- 配置了 `CODEX_HOME`：放入该目录下的 `skills/`。
- 默认位置：`~/.codex/skills/tccotoken/`。
- Windows 默认位置：`%USERPROFILE%\.codex\skills\tccotoken\`。

最终目录应包含 `tccotoken/SKILL.md` 和 `tccotoken/agents/openai.yaml`。重新打开 Codex 会话后调用：

```text
使用 $tccotoken 测算本机与非本机的 Codex 额度比例，说明统计时间范围、标定依据和不确定性。
```

Skill 是工作流程说明，不是独立运行的统计程序。执行时需要 Codex 能读取本机日志；如果账号额度工具不可用，可使用用户提供的官方额度快照。

## 方法

只有官方提供同口径完整 token 总数时，才直接计算“账号总 token − 本机 token”。官方只有额度百分比时，使用经验加权标定：

```text
本机加权用量 W = Σ(非缓存输入 × 输入权重 + 缓存输入 × 缓存权重 + 输出 × 输出权重)
每个百分点用量 k = 标定时段 W / 标定时段额度增长百分点
本机额度估计 L = 目标时段 W / k
未解释额度 R = 目标时段额度增长百分点 − L
本机占已用额度 = L / 目标时段额度增长百分点
未解释部分占已用额度 = R / 目标时段额度增长百分点
```

详细操作见 [SKILL.md](tccotoken/SKILL.md)。费率需查询[官方文档](https://learn.chatgpt.com/docs/pricing)，不固定沿用历史价格。

## 结果的适用范围

官方 credit 费率是权重代理，并非已公开验证的订阅额度扣减公式。若标定时段还包含其他设备使用、日志缺失或自动审查计费不明，差值只能称为“未解释额度”。它可能包含其他设备、云端任务和特殊来源，也可能来自标定误差。

敏感性范围不是置信区间；非本机实际使用可能接近零。原始 token 折算值依赖本机的模型和缓存构成，不能代表远端的真实 token 总数。

本仓库只发布通用方法和合成示例，不包含真实会话日志、账号额度快照、认证信息或个人路径。使用时无需上传原始日志到 GitHub。
